Used *ruby 3.4.7* and *Rails 8.1.2*.

## How to run

Follow these steps in the terminal:


# Install all the Gems
bundle install 

# Create the Database 
rails db:create

# Run the Migrations
rails db:migrate

# Start the server

First run 
./bin/dev 
to apply css. Then:
rails server

**Note:** use rails db:seed to seed the database.
